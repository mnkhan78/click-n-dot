# 🤍Click & Dot
A lightweight interactive web interface where users can click anywhere on the screen to drop a dot at that exact location. Built with HTML, CSS, and vanilla JavaScript, this project demonstrates event handling, DOM manipulation, keyboard shortcut support, and array-based undo functionality.

## Features
### 🖱️ Click to Drop Dots
Click anywhere on the screen to place a black dot at that position.

### 🗑️ Delete Last Dot
Click the Remove button to delete the most recently placed dot.

### ⌨️ Undo with Keyboard Shortcut
Press Ctrl + Z to undo the last deleted dot and restore it to the screen.

### 🔁 Array-Based Logic
Internally uses array to track and manage the order of placed and removed dots.

## 🛠️ Tech Stack
1. HTML
2. CSS
3. JavaScript (Vanilla)
